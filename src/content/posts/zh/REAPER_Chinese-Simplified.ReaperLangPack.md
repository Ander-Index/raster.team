# 这个汉化包有什么优势？
+ 持续更新，一般来说，REAPER 稳定版更新后的三天之内这里就同步跟上了。
+ 菜单里带图标是别家翻译没有的。（至少现在是……）
+ 由蠢老虎独裁，可以保证整个翻译的一致性。
+ 对于一些新兴词汇，在听取了各家建议后进行敲定。
+ 即使是纯文字版本，排版也美观。
+ 部分集中的重复文字，使用了独特的排列方式，使得寻找功能更加方便。

# ⚠️ 但是……
* Windows 的“显示语言”和“非 Unicode 程序的语言”均需要设置为简体中文时，Windows 11 专供的汉化才显示的最好。
    * 不然会导致因为其它语言的字符宽度不一样的缘故，导致对不齐
    * 后者会导致汉语显示为 "□□□"
    * 如果你一定要更改 Windows 显示语言，那么只有在系统缩放不为 100% 时才能对齐。
* macOS 和 Windows 的一些 Emoji 不通用，所以可能会出现图标与其他图标风格不同的问题，如果您发现了这样的问题，还请反馈给我，非常感谢～
* 我没有 Linux 这个系统，所以如果在 Linux 下出现了除翻译错误外的任何问题，我没有能力修复……
    * Linux 请朋友帮忙测试了，不过一开始朋友就表示了 Linux 本身对于其它语言的支持就是需要自己去配置环境什么的……我也不是很懂，所以 Linux 如果出现显示问题，我也没有能力去解决。
