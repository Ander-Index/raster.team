【Twine】Chapbook 简体中文指南

2026-03-17

嗨～这位对互动小说创作感兴趣的朋友～欢迎你～

如果您知道这是什么，想要直接去看教程，那么可以直接跳转了：/Sub-Sites/Chapbook_Gudie/index.html

这是什么？

我不知道您是如何找到这个页面的，也许是搜索 Twine，也许是搜索 Chapbook，再或者您只是从 Raster.Team 简单地进入本文章想要一看究竟。

那么……

Twine

Twine 本身只是一款节点式文本编辑器，它本身是不能做出活动小说的。就好比 Visual Code 本身是无法生成程序也不能理解程序的。

而 Twine 上有几款故事格式，你可以理解为“编程语言”，用 Twine 按照这些故事格式规定好的语法来撰写代码并构建。

而 Chapbook 就是一种非常容易上手的互动故事的格式，也是官方意图取代最开始的 Harlowe 格式的新格式。

Twine 和 Chapbook 都是开源免费的项目。

Chapbook

笔者已经深度使用过了 Inky、ChoiceScript、Chapbook。

而最终决定使用 Chapbook 替换掉 Inky 的原因是：

  1. 代码维护活跃：开发者每周都会积极查看案宗并处理合并请求。
  2. 不需要怎么修改也可以构建出很漂亮很现代的互动小说。

在使用一段时间之后，本人对该项目非常感兴趣，遂进行手册的本地化工作。

而今天，Chapbook 终于拥有了第一本非英语的译本～🎉

总结

如果您正在寻找互动小说的编写方案，那么欢迎你查看本人翻译的这份手册尝试一下。

Twine：https://twinery.org/

Chapbook 作为内置的故事格式本身就安装在了 Twine 里。

本站已经直接构建好了一份翻译：/Sub-Sites/Chapbook_Gudie/index.html

源代码已经提交到 Chapbook 官方代码库。
